# Microsoft Teams Integration Workflow Example

This example demonstrates the complete Todo-GPT workflow with Microsoft Teams notifications from task creation to completion.

## 📋 Scenario: Adding User Authentication Feature

Let's walk through a complete development workflow where Todo-GPT automatically implements a user authentication feature and keeps the team informed via Teams notifications.

### Step 1: Task Scheduling

**User Action**: Schedule a new task via the web interface

```json
{
  "title": "Add JWT-based user authentication",
  "taskType": "feature",
  "priority": "high",
  "scheduledTime": "2024-01-15T14:00:00Z",
  "projectPath": "/home/user/my-app",
  "description": "Implement secure user authentication system with JWT tokens",
  "requirements": [
    "Create login and registration endpoints",
    "Implement JWT token generation and validation",
    "Add authentication middleware",
    "Include password hashing with bcrypt",
    "Add comprehensive unit tests",
    "Update API documentation"
  ]
}
```

### Step 2: Task Started Notification

**Teams Message** (sent when task execution begins):

```
🚀 Todo-GPT Task Started
FEATURE • Priority: HIGH

Task: Add JWT-based user authentication
Type: feature
Priority: high
Project: /home/user/my-app
Scheduled: 1/15/2024, 2:00:00 PM

Implement secure user authentication system with JWT tokens
```

**What happens behind the scenes**:
- Todo-GPT analyzes the project structure
- Detects it's a Node.js/Express application
- Identifies existing patterns and dependencies
- Generates implementation plan

### Step 3: JIRA Ticket Creation

**JIRA Ticket Created**: `PROJ-456`
- **Summary**: Add JWT-based user authentication
- **Type**: Story
- **Priority**: High
- **Status**: In Progress
- **Description**: Includes all requirements and project context

### Step 4: Code Implementation

**AI Agent Actions**:
1. Creates authentication middleware (`middleware/auth.js`)
2. Implements user model with password hashing (`models/User.js`)
3. Creates authentication routes (`routes/auth.js`)
4. Adds JWT utilities (`utils/jwt.js`)
5. Generates comprehensive tests (`tests/auth.test.js`)
6. Updates API documentation

## 🔧 Customization Options

### Channel-Specific Notifications
```env
# Send different notifications to different channels
TEAMS_TASK_WEBHOOK_URL=https://outlook.office.com/webhook/dev-tasks
TEAMS_PR_WEBHOOK_URL=https://outlook.office.com/webhook/code-review
TEAMS_ERROR_WEBHOOK_URL=https://outlook.office.com/webhook/alerts
```

### Priority-Based Filtering
```env
# Only notify for high-priority tasks
TEAMS_NOTIFY_PRIORITY_THRESHOLD=high
TEAMS_MENTION_USERS_ON_URGENT=true
```

### Time-Based Controls
```env
# Quiet hours (no notifications)
TEAMS_QUIET_HOURS_START=18:00
TEAMS_QUIET_HOURS_END=09:00
TEAMS_WEEKEND_NOTIFICATIONS=false
```
